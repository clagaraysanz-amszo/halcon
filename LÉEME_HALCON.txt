3) USO DIARIO DEL SUPERVISOR — CARGAR EL PDO
------------------------------------------------------------------------
 1. Entrar como Supervisor.
 2. Panel -> "PDO del día" -> "Cargar PDO".
 3. "Subir PDO del día" -> elegir el archivo EXCEL del PDO (.xlsx).
 4. La app lee sola: la FECHA (del archivo), y cada Operador Drone con su
    TURNO (según la hora) y sus vuelos. Revisa el resumen.
 5. "Confirmar y distribuir PDO".

 NOTAS:
   - Se puede subir en CUALQUIER momento; la fecha la toma del archivo.
   - Un solo PDO cubre los 3 turnos, incluida la madrugada del turno noche
     (el día operativo cambia a las 07:00, no a medianoche).
   - Quien no aparezca en el PDO queda con día libre automáticamente.


4) USO DEL OPERADOR — REGISTRAR UN VUELO
------------------------------------------------------------------------
 1. Abrir app -> tocar su Halcón.
 2. "Realizar Tramo" o entrar a sus vuelos asignados -> elegir el tramo.
 3. Completar altura, minutos, aeronave, tipificación, estado.
 4. Permitir UBICACIÓN (GPS) la primera vez -> queda la posición del vuelo.
 5. "Confirmar". El supervisor lo ve al instante.
 6. Al terminar el turno: "Cerrar Sesión" (importante en equipo compartido).

6) TAREAS DE ADMINISTRACIÓN (en Supabase)
------------------------------------------------------------------------
 Todo esto se hace en supabase.com -> tu proyecto.

 A) CAMBIAR EL CORREO DE UN OPERADOR/SUPERVISOR
    SQL Editor -> New snippet -> Run (ejemplo):
       update public.operadores set email = 'nuevo@amszo.cl'
       where halcon_n = '3';
    OJO: el correo debe coincidir EXACTO con el usuario de Auth.

 B) AGREGAR / RECREAR EL USUARIO DE LOGIN
    Authentication -> Users -> Add user -> "Create new user"
    (NUNCA "Invite", da error de límite de correos).
      - Email: el mismo que quedó en la tabla operadores.
      - Password:
          * Operadores (Halcón 1-7): DEBE ser  HalconLB-2026
          * Supervisores: la que definas para cada uno.
      - Marcar "Auto Confirm User" -> Create user.

 C) VER LOS OPERADORES CARGADOS
    Table Editor -> tabla "operadores".

 D) BORRAR EL PDO DE UNA FECHA (si te equivocaste)
    SQL Editor:
       delete from public.pdo_dia where fecha = '2026-08-10';

10) PROBLEMAS COMUNES
------------------------------------------------------------------------
 • "Correo o contraseña incorrectos" (supervisor):
     -> el usuario de Auth no existe o la clave no coincide. Recrear con
        "Create new user" + Auto Confirm.
 • Un Halcón entra pero ve "Día libre" cuando debería tener vuelos:
     -> el PDO de esa fecha no se cargó, o la fecha del PDO no coincide
        con el día. Revisar en "Cargar PDO" la fecha y volver a subir.
 • La app se ve "vieja" tras un cambio:
     -> es la caché. Recargar la página (o cerrar y reabrir la app).
 • Al subir el PDO no detecta a alguien:
     -> revisar que el nombre del funcionario aparezca junto a su línea
        "SOBREVUELOS: ... SECTOR N" en el Excel.
